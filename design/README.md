# SiteResolve website design

Design source for the SiteResolve marketing website, built on the SiteResolve design system.
The live, interactive version is the Design canvas artifact:
https://claude.ai/artifact/FLAXevBX9qznXHZc4jvkqh

## What is here

- `canvas/Main.dc.html`: the whole website as one interactive artboard. It contains three layout
  versions of every page and a floating review bar to switch between them.
- `canvas/canvas.json`: the canvas index.
- `assets/`: the SiteResolve logo mark from the design system, trimmed and made transparent
  (ink and white variants).

## Layouts

| Layout | Name | Structure |
| --- | --- | --- |
| A | Ledger | Top navigation, split hero with the product beside the copy, 12-column rows, tabbed workflow stepper, pricing cards. |
| B | Record | Floating navigation, centred hero over a dark product band, numbered document sections, all workflow steps in sequence, pricing as wide rows. |
| C | Console | Fixed left rail, panel grid on a tinted background, workflow as four columns, tabular problem list, pricing comparison matrix. |

All three share the same copy, tokens and components so the comparison is about layout only.

## Pages

Home, Product, Solutions, Pricing, About, Contact, Careers, Privacy Policy, Cookie Policy,
Terms of Use, Waitlist confirmation, 404, plus an Interface messages reference page (review only,
not linked from the site navigation).

## Before public launch

Every bracketed placeholder (for example `[LEGAL ENTITY NAME]`) is highlighted and must be completed.
The legal pages are drafts until the placeholders are completed and legally reviewed. Export formats,
cookie table and analytics configuration also need confirming.
